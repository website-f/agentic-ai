# Screens index

Every menu screen in the app, with its menu label, its internal view name, where it is documented and its status.
The menu label can change by person: **Guards** shows as **People** to HR and leaders, and **Duty** shows as **My
details** to office staff.

Status key: **Main** = on `main`. **Candidate (#nn)** = only in the combined candidate (draft PR #nn).
**Main +** = on main and extended in the candidate.

Each screen section answers the same questions: what it is for, who sees it, what is on it, which actions and approvals it
offers, and which rules and data it uses.

## Shared pieces used on many screens

| Piece | What it does |
|---|---|
| **Record form** (Add / Edit) | One form for 26 plain record kinds, shown only to the record's keepers; the server checks again; every change is audited field by field. See [record forms](../reference/record-forms.md) |
| **Camera** | In-app camera only (no gallery); burns time, GPS and reference into the photo; the server checks place, distance, time and fingerprint |
| **Proof** | Attach stamped photos or documents (PDF or picture of a letter) to a step; fingerprints kept in the audit trail |
| **Witness** | The witness types their own staff number and PIN, so nobody can type a name for someone who was not there |
| **Signature pad** | A finger or stylus signature on another person's phone (for example a guard receiving an item from the OM) |
| **Face check** | Face recognition on the phone (free on-phone engine); the descriptor and photo go to the server, which compares with the face HR approved |
| **Guide cards** | Read-only step-by-step help per role, Bahasa Melayu first. See [guide cards](../reference/guide-cards.md) |
| **Leave panel** | Ask for leave or give an absence reason, decide, and correct a refused request |
| **Follow-up** | What the PIC or CMS did about an attendance alert |
| **Arisha** | The assistant, on every screen (see [overview](../01-overview.md#15-things-that-apply-on-every-screen)) |
| **Confidentiality** | The acceptance screen shown before first use |
| **Sign-in** | Microsoft 365 for staff; the person picker only in development and the test version |
